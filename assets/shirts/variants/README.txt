Colour variants of each piece: <piece>-moss.webp, -clay, -dusk, -sand.

They must have exactly the same framing and size as the main photo of that piece (800 x 960).
js/app.js lists them for each piece through V("<piece>"). Clicking a colour tag reveals the matching photo
rising from the hem. A piece with no variant photo falls back to a tint of the main photo.
